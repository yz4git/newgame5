# 星霊譚 — ASTRA TALES

**iPhone Safariで遊べる、DS時代のモンスター育成RPGから着想を得たオリジナルRPG。**

ハートゴールド／ソウルシルバーの設計から、フィールドと屋内マップの遷移、視線によるトレーナー戦、パーティ、PP、戦闘、経験値、捕獲、図鑑、セーブなどを独立実装しました。ゲーム本体のコード・キャラクター・地名・グラフィックはオリジナルです。公式ゲームのROM、素材、ソースコードを含みません。

## v0.18 森の記憶石・隠し通路・夕暮れの探索

- **3つの記憶石の探索パズル**：森の北側にある「葉」、西側の「しずく」、東側の「星」を正しい順序で調べると古い紋様が光る。順番を間違えても進行は失われず、石からヒントを読み取れる
- **地形そのものが変わる隠し通路**：3つの記憶石を点灯すると西側の蔦がほどけ、これまで通れなかった1マスが通行可能になる。奥の小部屋にはPP回復2個の報酬を配置
- **実際の通行判定とセーブが連動**：隠し通路の開閉はマップタイルに反映し、状態は `state.events.forestSecrets` に保存。再起動・ロード後も開いた通路が維持され、新規ゲームなら閉じた状態から開始
- **夕方・夜の月光の花**：森の中央付近で、夕方・夜だけ採取できる「月光の花」を追加。昼間はヒントが表示され、採取するとPP回復2個が手に入る。一度採取したら重複して入手できない
- **手掛かりの視覚表現**：3色の記憶石には発光する紋様、閉じた通路には絡みついた蔦、開いた通路には小さな光、月光の花には時間帯別の花びらの色を描画
- **ストーリーとは独立した寄り道**：森の本来の出口・トレーナー・泉を利用するのに謎解きは不要。プロローグが終わるまで仕掛けは作動しない
- **独立モジュール**：`src/forest-secrets.js` に紋様の順番・通路座標・時間帯条件・報酬取得状態を分離
- **追加テスト**：順番違いのヒント、3つの石への到達性、蔦に閉ざされた小部屋、通路開放後の移動、実際のゲーム内の報酬取得、保存・ロード後の復元、夕方・夜の一度きりの報酬、従来イベントの通しテスト

### セーブデータ互換性

過去の ASTRA TALES 保存データ（saveVersion=1）は初回ロード時に新しい成長パラメーターと空のボックスを追加して移行します。旧バージョンの保存データは導入イベントを終えた段階として読み込むため、進捗が巻き戻ることはありません。既存のHP、レベル、進行状況、所持金、捕獲済み情報は可能な限り引き継ぎます。ブラウザーのlocalStorageに保存されるため、Safariのサイトデータを消去するとデータが失われます。

### 実装上の位置付け

Nintendo DS向けのオリジナルプログラムを逐語的に移植したものではありません。ゲーム開始からのイベント構成や場面転換のリズムを参考にしていますが、登場人物・台詞・設定・イベント名・地名は独自制作です。UIも上下画面という構成を参考にした独自デザインであり、元の画面素材は使用していません。ゲーム内部の責務分離・戦闘ルール・育成処理・イベントフラグ等の設計を参考に、iPhone向けCanvas RPGとして独立した実装に置き換えています。ビルドやROMに依存しないブラウザー向けの構成です。

## 制限と今後

**ルールの互換性について：** 現段階は原作のゲームルールを参考にした独立実装です。弱点・急所・物理／特殊分離・天候などの一部を第4世代に近づけていますが、原作の全技・全特性・ダブルバトル・対人通信・ROM互換性を実現したわけではありません。原作のプログラムをそのまま移植したものとは区別してください。


**製品版ハートゴールドの完全再現ではありません。** 既存作品と同一の地方・人物・モンスター・台詞・素材・マップは採用していません。現状は短編RPGとして主要ループを遊べる段階です。

今後は街・道路・屋内の規模拡大、施設、長編イベント、タイルやNPCイベントのデータファイル化、より高密度な専用ドット絵・複数フレームのキャラクターアニメーション、天候・特性・育成ルールの拡充、実機でのフレームレート調整などを発展させられます。
