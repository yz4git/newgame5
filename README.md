# 星霊譚 — ASTRA TALES

iPhoneで遊べる、モンスター育成・探索RPGの初期プレイ可能版です。

ポケットモンスター ハートゴールド／ソウルシルバーの探索・バトル・捕獲・育成というゲーム構造を参考に、ゲーム本体は独立実装しています。オリジナルの世界観・星霊・描画・ロジックを使用し、ROM・ゲーム内素材・第三者ソースコードは同梱していません。公式移植ではありません。

## プレイ

GitHub Pagesを main ブランチの / (root) から有効化すると、以下から遊べます。

https://yz4git.github.io/newgame5/

また、index.html をブラウザーで開くだけでも動きます。依存パッケージやサーバーは不要です。

## 主な機能

- 4エリア：ミナモリの町、そよかぜの小道、月影の森、星降りの聖域
- 13種類のオリジナル星霊、9タイプの相性
- ターン制バトル、HP、経験値、レベルアップ、仲間の交代
- 草むらで野生の星霊に遭遇し、星玉で捕獲（最大6体）
- NPC会話、トレーナー戦、回復所、道具屋、ボス戦
- 星霊図鑑、旅の記録、ローカル自動セーブ
- スマートフォンのマルチタッチ十字キー、A/B/MENU、キーボード
- オリジナルの手続き描画、Web Audio効果音

## 操作

| アクション | タッチ | キーボード |
| --- | --- | --- |
| 移動 | 十字キー | 矢印 / WASD |
| 決定・話しかける | A | Z / Enter / Space |
| 戻る | B | X / Escape |
| メニュー | MENU | M |

町の北にある道を進み、森の奥の聖域を目指します。草むらでは野生の星霊が出現します。

## 技術

- HTML / CSS / JavaScript / Canvas 2D / Web Audio
- 外部ライブラリなし、サーバーなし
- Safari誤ズーム防止、タッチ入力、safe-area対応
- localStorageによるオートセーブ
- ホーム画面追加向けWeb App Manifest

## 現時点の制限

ハートゴールドを完全再現するものではなく、ゲームループを参考にした短編のオリジナルRPGです。今後、連れ歩き、屋内、長編シナリオ、施設、戦闘AI、BGM、アニメーション、データ駆動マップなどを段階的に拡張できます。
