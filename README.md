# 星霊譚 — ASTRA TALES

**iPhone Safariで遊べる、DS時代のモンスター育成RPGから着想を得たオリジナルRPG。**

ハートゴールド／ソウルシルバーの設計から、フィールドと屋内マップの遷移、視線によるトレーナー戦、パーティ、PP、戦闘、経験値、捕獲、図鑑、セーブなどを独立実装しました。ゲーム本体のコード・キャラクター・地名・グラフィックはオリジナルです。公式ゲームのROM、素材、ソースコードを含みません。

## v0.10 画面・アニメーション・音声の総合改善

- **オリジナルBGM12曲相当のシーン別テーマ**：町・自宅・研究所・道・森・湖・聖域・高原・タイトル・通常戦・ライバル戦・ボス戦。Web Audioの複数オシレーターでメロディー・低音・和音を合成し、地域・戦闘状態に合わせて自動切替
- **モバイル向け音声スケジューラー**：ユーザー操作から音声を開始。画面の更新に合わせて先読み再生し、バックグラウンド復帰など大きな時間ジャンプで発音が暴走しないよう制限
- **効果音の差別化**：足音は左右交互の低音で控えめに、攻撃時は技のタイプによって音程・波形・長さを変化。音声OFFはBGMにも連動
- **プレイヤーの歩行モーション**：方向ごとの顔と帽子、左右交互の足、腕振り、走行時の歩幅と足元の砂ぼこり
- **NPCの固有表現**：博士・家族・観測者・旅の友・トレーナーの髪型・衣装・目線・待機モーションを描き分け
- **地域ごとの描画密度向上**：草の揺れ、小花、森のキノコ、町の木柵、高原の光る結晶、湖面のさざ波。装飾は非衝突、同じ座標では常に同じ配置になる方式
- **建物をすべて描き分け**：星霊センターの十字看板、商店の日除け、研究所のアンテナ、自宅の煙突と植栽、観測小屋の天体ドーム
- **戦闘の視覚演出**：物理斬撃、炎、水、草、電気、岩、風、光・影を区別し、戦闘開始の画面ワイプとHP0時の消失アニメーションを追加
- **検証の追加**：全地域のCanvas描画、4方向のキャラクター、技ごとのアニメーション、音楽のテンポ・切り替え・消音・フレーム落ちを自動テスト
- 動作にサーバーや音声素材のダウンロードは不要。既存セーブと操作方法は変更せず利用可能

- ターン制戦闘、技演出、HP/EXPゲージ、敵トレーナー複数体との戦闘
- 視線と障害物を考慮したトレーナー自動対戦、ボス、クリア後のエリア
- HPに応じた捕獲、捕獲エフェクト、最大6体のパーティ、連れ歩き
- NPC会話、宝箱に相当する道具、買い物、回復とPP補充
- 図鑑、オートセーブ、継続プレイ、歩数・プレイ時間の記録
- **自由な名前入力**：主人公の名前を8文字まで入力可能。日本語キーボードとゲームの方向キー操作の競合も解消
- **相棒選択の専用画面**：研究所の3つの端末をカプセル状に描き分け、選択時は上画面に星霊の大型プレビューを表示
- **実戦型捕獲チュートリアル**：説明文だけでなく、弱った星霊との戦闘で自分でバッグを開き星玉を使用。成功後に本格的な捕獲を解放
- **イベントの演出順修正**：博士の緊急連絡は観測小屋から外に出た直後に発生し、重複発生を防止
- **ライバルの調査イベント**：帰還した研究所で調査員と会話し、ライバル名を選択してから博士に報告
- **専用NPC・調度品**：人型仮表示だった相棒端末、日記、階段、望遠鏡を固有の絵に変更。部屋ごとの床・壁・家具の色と質感を差別化
- **上画面の会話ポートレート**：博士・家族・観測者・調査員などのキャラクターを会話時に描き分け
- **セーブ保護**：進行済みセーブがある場合「はじめから」に確認を追加。以前のセーブから続ける機能を維持
- **オリジナルの連続ストーリー**：名前選択と導入会話 → 自分の部屋 → 家族との会話 → 研究所 → 3体から相棒選択 → 道具の受け取り → 家族に相棒を見せてギア入手 → 最初のおつかい → 湖畔の観測小屋 → 謎のかけらと図鑑 → 緊急連絡 → 帰路のライバル戦 → 博士への報告 → 捕獲チュートリアル
- **新しい屋内マップ**：自分の部屋、自宅1階、青凪の観測小屋。街の自宅と湖畔の木道を実際に歩いて出入り可能
- **13段階のイベント状態機械**：会話後の進行、イベント条件付きの移動制限、ライバルとの自動遭遇、クリア後の経路開放
- **ゲーム内の順序で機能解放**：相棒、アストラギア、図鑑、星玉での捕獲。早期のトレーナー戦を制限
- **初期イベント専用セーブ**：最初の星霊を受け取る前から進捗保存、ロード時に導入イベントを復元。既存セーブはクリア後モードで読み込み
- **ライバルの相棒の選択**：選んだ最初の星霊に有利なタイプの相手が登場。敗北しても物語は進行可能
- **通しテスト**：新規開始から捕獲の説明までの全主要イベント、マップの通行可能性、台詞進行、報酬の重複防止、途中セーブ
- **上下2画面の携帯機風UI**：上はフィールド・戦闘・図鑑プレビュー、下はタッチ操作メニューと選択肢
- **下画面の戦闘コマンド**：たたかう・バッグ・こうたい・にげるの4つを大きな2×2タイルで表示
- **技選択UI**：技の属性カラー、物理・特殊・変化の分類、残りPPをタイル表示
- **タッチパーティ**：2列×3体の仲間カード、HPゲージ、状態異常・レベル表示。個体詳細を開くと上画面に大型プレビュー
- **2画面連動図鑑**：下画面の一覧・詳細選択で、上画面に星霊を大きく描画
- **アストラギア**：現地時刻、エリア、踏破した場所、地域経路案内を表示
- フィールド中は下画面からメニュー・仲間・バッグ・ギアへ直接移動
- スマートフォン縦画面では上下積層、横画面では左右分割のレスポンシブ構成
- タッチ十字キー、A/Bボタン、走行モード、キーボード対応
- Canvas 2D / Web Audio / Web Storage、サーバー・依存パッケージ不要

### セーブデータ互換性

過去の ASTRA TALES 保存データ（saveVersion=1）は初回ロード時に新しい成長パラメーターと空のボックスを追加して移行します。旧バージョンの保存データは導入イベントを終えた段階として読み込むため、進捗が巻き戻ることはありません。既存のHP、レベル、進行状況、所持金、捕獲済み情報は可能な限り引き継ぎます。ブラウザーのlocalStorageに保存されるため、Safariのサイトデータを消去するとデータが失われます。

### 実装上の位置付け

Nintendo DS向けのオリジナルプログラムを逐語的に移植したものではありません。ゲーム開始からのイベント構成や場面転換のリズムを参考にしていますが、登場人物・台詞・設定・イベント名・地名は独自制作です。UIも上下画面という構成を参考にした独自デザインであり、元の画面素材は使用していません。ゲーム内部の責務分離・戦闘ルール・育成処理・イベントフラグ等の設計を参考に、iPhone向けCanvas RPGとして独立した実装に置き換えています。ビルドやROMに依存しないブラウザー向けの構成です。

## 制限と今後

**ルールの互換性について：** 現段階は原作のゲームルールを参考にした独立実装です。弱点・急所・物理／特殊分離・天候などの一部を第4世代に近づけていますが、原作の全技・全特性・ダブルバトル・対人通信・ROM互換性を実現したわけではありません。原作のプログラムをそのまま移植したものとは区別してください。


**製品版ハートゴールドの完全再現ではありません。** 既存作品と同一の地方・人物・モンスター・台詞・素材・マップは採用していません。現状は短編RPGとして主要ループを遊べる段階です。

今後は街・道路・屋内の規模拡大、施設、長編イベント、タイルやNPCイベントのデータファイル化、より高密度な専用ドット絵・複数フレームのキャラクターアニメーション、天候・特性・育成ルールの拡充、実機でのフレームレート調整などを発展させられます。
