# 星霊譚 — ASTRA TALES

**iPhone Safariで遊べる、DS時代のモンスター育成RPGから着想を得たオリジナルRPG。**

ハートゴールド／ソウルシルバーの設計から、フィールドと屋内マップの遷移、視線によるトレーナー戦、パーティ、PP、戦闘、経験値、捕獲、図鑑、セーブなどを独立実装しました。ゲーム本体のコード・キャラクター・地名・グラフィックはオリジナルです。公式ゲームのROM、素材、ソースコードを含みません。

## v0.2の内容

- 6つの屋外エリア（ミナモリの町・そよかぜの小道・月影の森・星降りの聖域・青凪の湖畔・星見の高原）
- 3つの屋内マップ（星霊センター・ミナモリ商店・アオイ研究所）
- 建物への出入り、道・草むら・樹木・橋・水辺・高原の地形、簡易昼夕夜表現
- 13種類のオリジナル星霊、9タイプ、技・HP・レベル・能力値
- 技のPP、タイプ一致補正、弱点・耐性、急所、命中率、まひ、やけど
- ターン制戦闘、技演出、HP/EXPゲージ、敵トレーナー複数体との戦闘
- 視線と障害物を考慮したトレーナー自動対戦、ボス、クリア後のエリア
- HPに応じた捕獲、捕獲エフェクト、最大6体のパーティ、連れ歩き
- NPC会話、宝箱に相当する道具、買い物、回復とPP補充
- 図鑑、オートセーブ、継続プレイ、歩数・プレイ時間の記録
- タッチ十字キー、A/Bボタン、走行モード、キーボード対応
- Canvas 2D / Web Audio / Web Storage、サーバー・依存パッケージ不要

## 操作

| 動作 | iPhone | キーボード |
| --- | --- | --- |
| 歩く | 十字キー | 矢印 / WASD |
| 決定・会話 | A | Z / Enter / Space |
| 走る切り替え（フィールド） | B | X |
| 戻る | B | X / Escape |
| メニュー | MENU | M |

町の北から探索開始。小道の東に湖畔への脇道があります。森の先にある聖域で「星のしるし」を取得すると、高原へも行けます。

## テスト

```bash
node tests/smoke.cjs
```

外部パッケージ不要のスモークテストで、開始処理、マップ移動、屋内出入り、サブエリア、ボス後のエリア解放、トレーナー視線、技PP、捕獲、ローカル保存、描画の基本経路を検証します。GitHub Actionsがデプロイ前に自動実行します。

## 制限と今後

**製品版ハートゴールドの完全再現ではありません。** 既存作品と同一の地方・人物・モンスター・台詞・素材・マップは採用していません。現状は短編RPGとして主要ループを遊べる段階です。

今後は街・道路・屋内の規模拡大、施設、長編イベント、NPCスクリプト、戦闘アニメーションと専用ドット絵、天候・特性・持ち物・育成の深さ、サウンドトラックなどを発展させられます。
